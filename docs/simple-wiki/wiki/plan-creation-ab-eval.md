# 计划创建 A/B 评估：go-spec 0.4 vs writing-plans

> 2026-09-07 阶段评估汇总（报告 v0.1，n=1，方向性结论）。评估契约：同模型（glm-5.3-flash）生产 + strict 审查，主持人按冻结的 [Truth Card：学者双语阅读](../raw/2026-09-07-plan-creation-truth-card.md) 以用户第一人称应答，strict 合同预注册（需求忠实度 + 可施工性）。场景：表面方案「划词翻译小工具」包裹真实需求「双语对照阅读」。全程未施工代码，终点 = 实施计划完成。

## 结果总览

| 维度 | A：writing-plans | B：go-spec 0.4 |
|---|---|---|
| strict 结果 | R1 FAIL（2 FATAL）→ R2 PASS（4 WARN + 4 MINOR） | R1 PASS（0 FATAL，7 WARN） |
| 需求重构 | 未发生；strict 逼出后部分回归 | grill 第 2 轮自发完成，贯穿终稿 |
| 澄清结构 | 1 回合 5 问（参数层） | grill 2 轮 10 问（需求层 + 参数层） |
| 决策点覆盖 | 约 3.5/10 | 约 8.5/10（含加分项术语沉淀） |
| 生产时长 | 39.6 分钟（三版：作废大半 + 重写 + 终稿） | 16.5 分钟（一次过闸 + 执行层 + 切片） |
| 全链时长（含 strict） | 50.7 分钟（strict 2 轮） | 21.6 分钟（strict 1 轮） |
| 终稿形态 | 2047 行，69% 内嵌代码，12 任务线性 | 430 行主文档 + 7 切片，7% 契约代码，4 里程碑按风险切分（M1/M2 并行论证） |
| 术语加分项 | 未挖到，显影为设计盲点（跨块术语漂移） | 挖到并设计为一级功能（跨篇术语本） |

## 判词

- A 用 2.3 倍时长、4.8 倍篇幅、手册级代码预支交付了工程扎实的产品计划，但产品方向第一枪打错，靠 strict 逼回；用户立场的部分内容（术语统一）始终不可见。
- B 在信息层（grill）完成需求重构，一次过闸；评审意见被下一层消化而非触发重写；切片与里程碑为后续分派就绪。代价：执行者需要判断力（承诺立场，本轮未施工验证）。
- go-spec 设计合理性获第二个实证支持：决策层/grill 对「需求重构」的承载力是 writing-plans 方法论结构上不具备的（同素材、同模型）。机制展开见 [分层停点与需求重构](layered-stops-requirement-reframing.md)。
- 后续指向：executor 施工冒烟（承诺立场的最终试金石）已完成——施工段与全管线结论见 [Executor 施工冒烟：M1 段 A/B 对照](executor-smoke-m1-ab.md)。

## strict 表现与过程事件

- 判罚一致：同一合同 + 同一卡。对 A 两轮精确递进（R1 抓方向、R2 验证修复真实性并抓残留）；对 B 的 7 WARN 均有施工级依据（伪造用户立场、三处契约空洞）。各轮主动核查访谈合规并标注 UNVERIFIED——审查者知道自己看不见什么，判词质量可信。
- 一处可辩裁量（如实记录）：A R2 以体验判准把「左英右中并排 vs 口径 3 按需展开」降为 WARN 而非 FATAL，属合同解释空间，非判罚不一致（B 精确按口径设计，无对应物）。
- 效度缝隙：主持人对卡上无口径的「自研 vs 现成」做了 1 处裁量应答（「想自己弄一个」），进产物后被记为「用户已确认」，strict 判归类失实（W2）。修正约定：裁量应答须同步追加至卡附注（或过程日志），保持 strict 视野完整。
- 跨轮核验链小缺口：A R2 未提供 R1 WARN 逐条原文核对，仅确认对应机制存在。
- 基建：上轮 2 小时卡死 ×2 未复现，通知信道本轮可靠；子代理通知 token 字段仍全 0，改由 JSONL 转录逐消息聚合恢复，数据完整。

## 价值核算（方向性）

- 生产成本（旧锚计价：以 flash 峰价为跨服务商锚整体折算，后续已改为官方峰价分档口径，见 [Executor 施工冒烟：M1 段 A/B 对照](executor-smoke-m1-ab.md)）：A 线 $0.313 / B 线 $0.121；含 strict 分线 $0.369 / $0.145（B 为 A 的 39%）。
- 单评估者质量分（需求忠实 35 / 可施工 25 / 结构与分派 20 / 决策透明 10 / 返工经济 10）：A ≈ 70（重构后置 + 术语盲点 + 账本残留失实），B ≈ 93（前置重构 + 契约承接 + 切片就绪）；每分价格 B 优约 3.4 倍。
- A 的超额成本主要计在生成与冷输入（三版重写），cache 重放非大头——与「减少 turn 数、压薄常驻上下文」双杠杆一致。
- 评估基建税：主会话 $0.765 超过两条生产线总和（$0.514），源于编排者上下文重放；靠 truth card / 合同 / 脚本复用摊薄（本轮已物化为可复用资产）。
- 本会话总账 ≈ $1.31（谷时约 $0.65）。
