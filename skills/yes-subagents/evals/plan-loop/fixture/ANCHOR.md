# 判级锚：notes-cli 多设备同步计划（v1 审查时点）

> 由计划作者（Orchestrator）提供，用户已确认。只包含判级信息，不含设计理由、取舍或替代方案。

## 第一用途

这份计划要指导团队把 notes-cli 从单机改为多机同步：让用户在任意机器上编辑后，能安全同步到其它机器，并在冲突时不丢数据、不静默覆盖。

## 成功标准

1. **不丢数据**：离线编辑后联网自动同步，任意操作顺序下不丢失笔记内容。
2. **冲突可感知**：发生冲突时用户能知道是哪些笔记，并能选择保留哪一版；不得静默覆盖任一版本。
3. **可接续**：新的会话只读状态文件，就能判断同步进度、待处理项与下一步动作。
4. **可恢复**：同步失败可重试，且不产生重复笔记或重复冲突记录。

## 非目标

- 实时协作、多人同时编辑同一笔记；
- 端到端加密；
- 移动端、Web UI；
- 服务端全文搜索与分享链接。

## 不可接受的失败形态

- 任一版本被静默覆盖；
- 同步中断后笔记内容丢失或重复；
- 新会话无法判断同步是否完成、下一步做什么；
- 冲突记录重复堆积，或用户反复处理同一冲突。
