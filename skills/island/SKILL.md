# Island（门户）

用户只需记住 **`/island`**。本技能是薄门户：听意图 → 查路由表 → 交给对应地标技能。地标未就绪时如实说，不假装可用。

## 边界

| 做 | 不做 |
|---|---|
| 把自然语言意图映射到地标 | 自己当图书馆 / 酒馆 / 规划台 |
| 指向已有 `skills/<id>/` 并让对方读其 SKILL | 发明第二套路由表或旁路入口 |
| 地标未建时说明「未就绪」 | 把未就绪写成已可用承诺 |

## 工作方式

1. 收一句意图（`/island …` 或等价说法）
2. 用下方**路由表**匹配地标（先精确，再模糊；多义时问一句澄清）
3. 若地标有技能目录 → 读并执行该 `SKILL.md`
4. 若标为未就绪 → 一句话说明，可建议最近的已就绪入口（通常是招募）
5. 不要把业务逻辑写回本文件；路由变更才改本表

## 路由表（草案）

| 意图信号（例） | 地标 | 技能 | 状态 |
|---|---|---|---|
| 招募 / 设计岛民 / 写角色说明书 / 新 subagent 角色 | 招募台 | `skills/recruit` | **就绪** |
| 查知识 / wiki / 图书馆 / 记一条可复用真源 | 图书馆 | （待建） | 未就绪 |
| 组队 / 酒馆 / 这个项目要谁 / 选人派工 | 小酒馆 | （待建） | 未就绪 |
| 规划 / 切片计划 / spec / 开一条可执行计划 | 规划台 | （待建） | 未就绪 |
| 慢慢聊 / 篝火 / 沉思对话 / fireside | 篝火边 | （待建） | 未就绪 |
| 设计落地 / 设计工作室 / sketch | 设计工作室 | （待建） | 未就绪 |
| handoff / 交接 / 恢复上次状态 | 交接处 | （待建） | 未就绪 |
| 指引 / 搬家 / 怎么开始用岛 | 引导 | （待建） | 未就绪 |
| 只说了 `/island` 或「上岛」无下文 | — | 本技能 | 列出已就绪入口 + 门廊 `AGENTS.md` |

模糊匹配原则：动词/对象贴近上表「意图信号」即可；不确定时先问「是要招募、查知识，还是组队？」这类短澄清，选项只给表内已列意图。

## 与码头（可选，未钉死）

仓库内可选 `/.island`（或其它 dock 名）作「泊靠」标记，便于宿主发现本岛。**命名与是否采用尚未裁定**；未裁定前不要当硬依赖。门户路由不依赖 dock 是否存在。

## 演进

- 新地标就绪：在路由表补一行，并把「技能」列改成真实路径；同步 `AGENTS.md` Landmarks（若需要）
- 用户心智仍只记 `/island`；不要另开并列一级入口技能与本门户抢路由
- 思想可借鉴既有旅程/harness 技能，本岛路径与命名以本仓为准
